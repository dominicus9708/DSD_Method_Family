# 05. DSD Synthesis / DSD 합성론

Status: **proposed**

Task: compose admissible components, properties, or candidate structures into a larger construction while preserving the conditions under which the composition is legitimate.

Primary DSD sources: Formation Clause-VII-compatible composition interfaces, General Property typing, and Static Aggregation when analytic outputs are combined.

Primary questions:
- which parts are independently admitted;
- which composition rule is actually supplied;
- which cross-part dependencies must hold;
- whether composition loses support or typed relations;
- whether the synthesized result requires a new formation model.

Boundary: this method does not infer that all components are composable merely because they coexist or share labels.
