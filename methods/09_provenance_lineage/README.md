# 09. DSD Provenance-Lineage / DSD 추적·계보론

Status: **developing**

Task: preserve where a structure, datum, interpretation, component, or successor relation came from and how it changed or was transmitted.

Primary DSD sources: formation traces, support-retaining records, dynamic channel/component lineage, transition classes.

Typical outputs:
- origin and derivation chain;
- source-copy-edition-interpretation lineage for documentary cases;
- pre/post-transition successor relations;
- missing-link and ambiguous-lineage records;
- provenance confidence/evidence ledgers kept separate from object status.

Boundary: lineage is explicit additional data when identity is not inherited automatically; similarity alone does not establish succession.
