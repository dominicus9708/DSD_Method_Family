# Legacy Compatibility Wrapper: Provenance-Lineage / 호환성 묶음: 추적·계보

Status: **legacy compatibility wrapper — not counted as a method**

This path is preserved so earlier links and records remain valid. It does not define one combined DSD method.

이 경로는 과거 링크와 기록 호환성을 위해 유지하며, 하나의 합성 DSD 방법으로 계수하지 않습니다.

Independent methods:

- [`provenance/`](provenance/) — **DSD Tracking / DSD 추적론**: canonical method name; legacy directory retained for compatibility. Provenance / 출처·유래 추적 is the origin/derivation subcase.
- [`lineage/`](lineage/) — **DSD Lineage / DSD 계보론**: predecessor/successor identity across dynamic or formation-level change; internal standardization currently in progress.

Both are classified under **Field IV. Evidence & Lineage / 분야 IV. 증거·계보**, but field membership does not merge them.

The distinction is deliberate: a Tracking trace can be known without proving successor identity, and Lineage requires an admissible succession relation or the source-defined fixed-background canonical condition rather than origin similarity, label continuity, or temporal adjacency alone.
