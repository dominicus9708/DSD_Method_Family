# Legacy Compatibility Wrapper: Computation-Optimization / 호환성 묶음: 계산·최적화

Status: **legacy compatibility wrapper — not counted as a method**

This path is preserved for earlier links and records. It does not define one combined DSD method.

Independent methods:

- [`computation/`](computation/) — **DSD Computation / DSD 계산론**: determine which branches, channels, dependencies, resolutions, and reusable common parts must actually be evaluated.
- [`optimization/`](optimization/) — **DSD Optimization / DSD 최적화론**: choose among admissible computational, structural, scheduling, or resource-allocation alternatives under explicit objectives and constraints.

Both are classified under **Field VII. Computation & Selection / 분야 VII. 계산·선택**, but remain independent.

Computation asks what must be calculated and how; Optimization asks which admissible strategy is preferable. Every pruning rule requires a soundness argument, and every optimization requires explicit objectives and constraints.
