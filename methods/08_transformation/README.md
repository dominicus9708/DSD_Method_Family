# 08. DSD Transformation / DSD 변환론

Status: **proposed**

Task: move data or structure from one representation, model, schema, or regime to another while recording what is preserved, reflected, merged, omitted, or newly supplied.

Primary DSD sources: forward maps, embeddings, strict equivalence, analytic transport/covariance, explicit property and dynamic bridges.

Typical outputs:
- source/target typing map;
- preserved and non-preserved status distinctions;
- bridge assumptions;
- information-loss record;
- conditions for reversible transformation.

Boundary: transformation is not considered faithful merely because final numerical outputs coincide.
