# 10B. DSD Compression / DSD 압축론

Status: **proposed/developing**

Task: reduce representation size or resolution while preserving the distinctions required by a declared downstream purpose.

Primary DSD sources: aggregation collision/kernel criteria, support-retaining descriptors, required resolution, optional dynamic readouts.

Typical outputs:
- purpose and retained-distinction set;
- compression map and sidecar information;
- acceptable versus destructive collision classes;
- reconstruction limits;
- resolution-dependent compression profile.

Boundary: smaller data are not automatically better; compression quality is judged against explicitly required distinguishability and reconstruction goals.
