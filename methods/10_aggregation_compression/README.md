# 10. DSD Aggregation-Compression / DSD 집계·압축론

Status: **developing**

Task: construct reduced readouts, summaries, or compressed representations while making the resulting information loss explicit.

Primary DSD sources: Channel-Indexed Static Aggregation, support-retaining data, exact kernel/injectivity criteria, optional dynamic readouts.

Typical outputs:
- aggregation map and support definition;
- collision witnesses;
- kernel/injectivity conditions;
- retained sidecar information;
- declared reconstruction limits;
- purpose-dependent compression profile.

Boundary: a smaller representation is not automatically a better one; required distinguishability must be specified before compression quality can be judged.
