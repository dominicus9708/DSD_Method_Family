# 06. DSD Comparison / DSD 비교론

Status: **developing**

Task: compare two or more structures without reducing comparison to final-output equality.

Primary DSD sources: strict equivalence, structure-preserving maps, stage comparison, first branching, property-stage comparison, and optional dynamic lineage comparison.

Typical outputs:
- preserved coordinates and relations;
- direct/partial/encoded/non-correspondence;
- earliest supported branching stage;
- aggregate collisions despite structural difference;
- comparison limits when no common bridge exists.

Boundary: first branching requires exhaustion or justification of the relevant comparison family, not failure of one arbitrarily chosen map.
