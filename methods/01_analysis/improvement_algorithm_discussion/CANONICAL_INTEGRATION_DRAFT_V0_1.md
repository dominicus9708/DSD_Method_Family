## 4. Method-boundary protection

### Analysis vs Computation

Analysis may identify:
- repeated descriptor;
- reusable prefix;
- unnecessary branch;
- required resolution.

Computation owns:
- deciding what is actually evaluated;
- cache/memoization/reuse implementation;
- measured complexity or run-time gain.

Therefore temporary ANA-Δ07 is not a new Analysis core rule.

### Analysis vs Compression

Analysis/Audit may detect information loss.

Compression owns:
- intentional representation reduction;
- proof that purpose-required distinctions survive the reduction.

Therefore information-loss detection does not absorb Compression.

### Analysis vs Operation

Analysis may classify frontier/supporting/dormant work structurally.

Operation owns:
- lifecycle coordination;
- resources;
- monitoring;
- handoff;
- repeated live method orchestration.

Therefore frontier admissibility is not a resource scheduler.

### Analysis vs Comparison / Classification / Interpretation

No change to the existing boundary matrix.

## 5. Historical compatibility rule

- additive, not retrospective validity conditions.
