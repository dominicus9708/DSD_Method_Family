# Field VII. Computation & Selection / 분야 VII. 계산·선택

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Computation / DSD 계산론`](../../12_computation_optimization/computation/) — determine what must be evaluated, which dependencies matter, and what can be safely omitted or reused.
- [`Optimization / DSD 최적화론`](../../12_computation_optimization/optimization/) — choose among admissible alternatives under explicit objectives and constraints.

Computation determines the required evaluation structure; Optimization selects among admissible strategies. Neither guarantees reduced complexity without an explicit soundness and cost analysis.
