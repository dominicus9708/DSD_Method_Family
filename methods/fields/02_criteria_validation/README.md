# Field II. Criteria & Validation / 분야 II. 기준·검증

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Specification / DSD 명세론`](../../03_specification/) — declare what must be defined, distinguished, constrained, and accepted.
- [`Audit / DSD 감사`](../../02_audit/) — retrace evidence, procedure, bridges, scope, and verdict rules under an explicit standard.

Specification supplies declared criteria or contracts; Audit evaluates whether a case, process, calculation, or claim satisfied the relevant criteria. Neither is reduced to the other.
