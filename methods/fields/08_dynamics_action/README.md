# Field VIII. Dynamics & Action / 분야 VIII. 동역학·행동

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Simulation / DSD 시뮬레이션론`](../../13_simulation/) — evolve admissible trajectories under a declared model.
- [`Prediction / DSD 예측론`](../../18_prediction/) — assert a future target under explicit empirical/domain validation requirements.
- [`Control / DSD 제어론`](../../14_control/) — choose interventions intended to move a system toward target states.
- [`Operation / DSD 운영론`](../../17_operation/) — coordinate repeated lifecycle, monitoring, resource use, handoff, execution, and method composition.

Simulation, prediction, control, and operation frequently interact, but model evolution, future-target claims, intervention choice, and lifecycle execution retain separate success criteria.
