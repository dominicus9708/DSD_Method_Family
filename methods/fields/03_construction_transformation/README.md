# Field III. Construction & Transformation / 분야 III. 구성·변환

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Design / DSD 설계론`](../../04_design/) — construct a target structure from requirements and constraints.
- [`Synthesis / DSD 합성론`](../../05_synthesis/) — combine admissible components under explicit composition rules.
- [`Transformation / DSD 변환론`](../../08_transformation/) — move between representations, models, or schemas while recording preservation and loss.

Design, synthesis, and transformation may appear in one workflow, but they have different inputs and success criteria and are not merged into one method.
