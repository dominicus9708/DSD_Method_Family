# Field I. Structural Description & Understanding / 분야 I. 구조 기술·이해

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Analysis / DSD 분석론`](../../01_analysis/) — decompose an existing target into explicit structural distinctions.
- [`Comparison / DSD 비교론`](../../06_comparison/) — compare preserved structure and locate first branching.
- [`Classification / DSD 분류론`](../../07_classification/) — classify by structural/property/equivalence criteria rather than labels alone.
- [`Interpretation / DSD 해석론`](../../16_interpretation/) — separate source, premises, interpretive bridge, and resulting reading.

The field does not imply that interpretation is reducible to analysis, or that classification is merely a subtype of comparison.
