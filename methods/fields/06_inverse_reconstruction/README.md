# Field VI. Inverse Inference & Reconstruction / 분야 VI. 역추론·복원

Classification role only. The methods below remain independent.

분류용 상위 분야이며, 아래 방법들은 서로 독립적으로 유지합니다.

- [`Diagnosis / DSD 진단론`](../../15_diagnosis_reconstruction/diagnosis/) — infer present hidden states, failure modes, causes, or structural conditions compatible with observations.
- [`Reconstruction / DSD 복원론`](../../15_diagnosis_reconstruction/reconstruction/) — infer prior, omitted, damaged, or compressed structures and histories compatible with evidence.

Diagnosis primarily addresses present hidden structure; Reconstruction primarily addresses prior or missing structure. Non-identifiability must remain explicit in both.
