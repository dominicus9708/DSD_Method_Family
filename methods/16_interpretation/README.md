# 16. DSD Interpretation / DSD 해석론

Status: **proposed**

Task: separate source material, contextual prerequisites, interpretive bridge, and resulting reading so that competing interpretations can be compared without treating one representation as the source itself.

Primary DSD sources: Formation/Property distinctions, explicit bridges, provenance-lineage, Static Aggregation when summaries are used, Dynamics when interpretation depends on temporal sequence.

Typical outputs:
- source/provenance layer;
- interpretive assumptions and applicability conditions;
- bridge from source features to interpretive claims;
- alternative readings and first branching;
- distinction between source fact, reconstruction, and interpretation.

Candidate case: a DSD reinterpretation of the received Sunzi / *The Art of War* can serve as an early humanities benchmark, provided textual criticism and military-historical scholarship remain external standards rather than being replaced by DSD.
