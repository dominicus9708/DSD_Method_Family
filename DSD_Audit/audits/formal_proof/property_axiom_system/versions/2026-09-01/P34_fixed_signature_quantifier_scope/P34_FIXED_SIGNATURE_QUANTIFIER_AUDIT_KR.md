## 1. 원문 출발점과 양화의 종류

P27 Theorem 11.1은 `Fix a Stage-VI DSD formation record FVI and a shared property signature Sprop.`로 시작하고 13개 결론을 나열한다. 제11절 결론 (3)은 PI·PII 상호 비도출, (11)은 분기 2·3·4의 유한 존재 증인, (12)는 단순 속성 집계가 엄격 동형을 분류하지 못한다는 주장이다. §4는 공통 **특정 증인 시그니처**로 반모형을 만들고, §8–9도 **특정 선택 가능 시그니처**의 존재 모형을 만든다.

두 논리 명제는 다르다:

- **고정 시그니처 전칭 진술 U:** `∀FVI ∀Sprop (valid(FVI,Sprop) ⇒ P(FVI,Sprop))`.
- **시그니처 계열 존재 진술 E:** `∃ valid Sprop` (필요하다면 고정 FVI에 상대적으로) `∃ model or typed premodel witnesses`.

P31의 반례는 `Saux=∅`, `Π̂=∅`인 허용 공유 시그니처 아래 정규 제한 원시좌표 가족의 단 하나의 모형을 사용한다. 해당 고정 시그니처에서는 (3)의 양측 원시공리가 모두 공허한 정리이며 (11)의 분기 증인과 (12)의 같은 요약·비동형 쌍이 존재할 수 없다. 그러므로 **U로 읽은 §11 (3)/(11)/(12)는 거짓이며 E로 읽은 기존 개별 증명까지 반증되지는 않는다.** 이는 원시공리계 자체의 무모순성을 인증하는 결과도 아니다.

## 2. 독립 명제 P34-A: 고정 시그니처의 두 원시공리 상호 독립

공유 시그니처에 한 후보 속성 `p`, 값 공역 `Z_p`에서 적어도 하나의 값 `z`, 빈 것이 아닌 적법한 입력곱 `X_{A,p}`에서 입력 `x`, 그리고 최소 하나의 선행조건 `d∈δ(p)`가 존재하고, 그 입력 운반체를 공급할 수 있다고 하자.

- **PI 위반·PII 만족 전모형:** 선언 `p`; `Dom Ξ_p={x}`, `Ξ_p(x)=z`; `Ap_p=∅`; 모든 `d'∈δ(p)`에 대해 `Sat_{p,d'}={x}`.
- **PI 만족·PII 위반 전모형:** 동일한 서명과 원시 할당; `Ap_p={x}`; 선택한 `d`에 대해 `Sat_{p,d}=∅`, 다른 모든 선행조건은 `{x}`.

양쪽은 값·입력·관계가 적법하게 타입화된 **전모형**이다. 어느 쪽도 두 공리를 모두 만족하는 완전 코어라고 주장하지 않는다. 이로써 위 조건을 충족하는 **고정된 하나의 시그니처에서도** 상호 비도출을 얻는다.

반면 `δ(ω)=∅`가 모든 후보 종류에 성립하면 정의상 `DepSat_{A,ω}=X_{A,ω}`이고 typed partial assignment의 정의역은 항상 해당 곱의 부분집합이므로 PII는 모든 타입 전모형에서 참이다. 또한 모든 이용가능 후보의 입력곱이 비거나 모든 값 공역이 비면, PI/PII를 위반하는 정의된 할당 자체를 구성할 수 없다.

**판정:** 주어진 충분조건에 대한 일반 구성은 집합의 크기에 의존하지 않고 증명됨; 고정 시그니처 전칭 독립성은 반모형으로 부정. 완전한 필요충분조건의 모든 예외를 형식화했다고 주장하지 않음.

## 3. 독립 명제 P34-B: 분기 단계 2·3·4에 필요한 증인 자원 축소

P33의 **정규 제한 가족 해석 A**와 단계비교집합 `I_k` 공식에 상대적으로 판단한다. 기존 §8.3의 구성은 올바른 존재 증인이지만 조건이 최솟값이라는 주장은 원문에 없다. 이하의 더 작은 증인은 그 사실을 확인한다.

### (i) 단계 2: 후보 속성 하나면 가능

`Π̂`에 `p`가 존재한다고 하자. 같은 보조 운반체 공급을 가진 두 모형에서 `Π_A={p}`, `Π_B=∅`로 둔다. `p`의 프로필이 미공급이어도 활성 원시자료는 양쪽에 없으므로 타입상 문제가 없고 `I_1≠∅`, `I_2=∅`. 속성의 값 공역이 비어도 적용 가능.

### (ii) 단계 3: 속성 하나 + 입력 하나면 가능

`σ(p)=(u)`, 제공된 `X(u)={a}`. 양쪽은 `Π={p}`, 할당 미정의, 모든 선행조건 충족 집합 동일(혹은 선행조건 없음). 한쪽 `Ap_p=∅`, 다른 쪽 `Ap_p={(a)}`이면 `I_2≠∅`, `I_3=∅`. 값 공역이 비어도 할당이 없어 모델은 적법하며 구성은 성립.

### (iii) 단계 4: 속성 하나 + 입력 하나 + 값 하나면 가능

동일 서명·공급·선언 및 `Ap_p={(a)}`와 모든 선행조건 충족을 양쪽에 준다. 값 `z∈Z_p`가 있을 때 한쪽 `Ξ_p`는 공함수, 다른 쪽은 `Ξ_p((a))=z`로 둔다. 모든 단계 3 좌표가 같아 `I_3≠∅`이고 할당 정의역이 다르므로 `I_4=∅`. 둘 이상의 값이나 속성은 불필요하다.

이 세 구성은 **가능한 시그니처가 존재하는 계열 수준**에서 (11)을 지지한다. 모든 고정 시그니처에 세 단계 증인이 각각 있다는 주장은 여전히 거짓이다. 특히 공유 상속 입력 운반체가 빈 집합이어서 모든 후보 입력곱이 비면, 적용가능성/할당 차이는 만들 수 없다.

## 4. 독립 명제 P34-C: 요약 충돌은 값 상관관계 손실만으로 제한되지 않음

P27 정의 9.1의 요약은 속성별 `(p, |D_p|, N^0_p, N^{≠0}_p)`을 보존하지만 `Ap_p`와 원시 선행조건 만족 집합은 담지 않는다.

**더 작은 증인 1 — 속성 하나, 입력 하나, 영값 하나:**

공유 시그니처에 zero-bearing 후보 `p`, `σ(p)=(u)`, `X(u)={a}`, `Z_p={0}`를 둔다. `Π_A=Π_B={p}`, 양쪽 할당 `Ξ_p`는 공함수, 모든 선행조건 만족 자료는 동일; 단 `Ap_{A,p}=∅`, `Ap_{B,p}={(a)}`로 다르게 둔다. 양쪽은 property-finite 및 P27 Def9.1의 적용조건을 만족하고

`S(A)=S(B)=(1,{(p,0,0,0)})`

지만 `I_3(A,B)=∅`이므로 엄격 동형이 아니다. 원래 §9.1의 **두 속성 간 값 상관관계 손실 증인도 유효**하지만, 이 구성은 **적용가능성 정보 자체의 손실**을 분리해 보여준다.

**더 작은 증인 2 — 선언한 속성이 전혀 없어도 부가 타입 가용성 차이가 있으면 가능:**

`Saux`에 정렬 `u`가 있고 후보 속성 집합은 비어도 된다. `Π_A=Π_B=∅`; A는 `u`를 공급하지 않고 B는 빈 집합 운반체 `X_B(u)=∅`를 공급한다. 양쪽 P27 요약은 `(0,∅)`로 동일하지만 S2(공급된 종류 집합 동일)를 만족하지 않으므로 엄격 동형이 아니다. 여기서 **공집합 운반체를 공급함**과 **운반체가 미공급됨**은 서로 다른 상태이다.

**예외:** `Saux=∅`, `Π̂=∅`이고 잉여 좌표 없는 정규 모형 해석에서는 유일한 완전모형 하나만 있어 이 같은 충돌이 불가능하다. 따라서 (12)의 올바른 판정도 고정 서명에 대한 일반 비분류가 아닌 **적법한 시그니처와 모형쌍에 대한 존재적 비분류**이다.

§9의 Remark는 기존 두 속성 증인에 대한 설명으로는 그대로 유효하다. 그러나 이 논문의 정보손실 원인이 항상 *속성 간 상관관계*에 한정된다고 일반화해서는 안 된다.
