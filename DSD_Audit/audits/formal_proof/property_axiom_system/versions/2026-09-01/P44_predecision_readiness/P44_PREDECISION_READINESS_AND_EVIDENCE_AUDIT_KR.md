## 2. P44 신규 병렬 확인 — 인라인 수식 222개씩

P43은 `\\[...\\]` 표시수식을 **언어당 78개** 검사했으나 `\\(...\\)` 인라인 수식은 완전 대조 대상이 아니었다. 본 P44는 동결 EN/KR LaTeX에서 본문/부록 16개 절의 인라인 수식 **각각 222개**를 추출해 공백/문장부호/`\\text{...}` 현지화 설명을 정규화하고 절 단위의 **다중집합**을 대조한다.

- 16개 절 중 제6절의 국문에만 수식 `\\Phi` 표시가 **1회 더 많다**. 실제 위치는 속성 매장을 정의하면서 "사상 `\\Phi`를 속성 매장이라 한다"는 문장이다. 영문에도 동일한 사상이 문장으로 규정된다.
- 제7절 영문에만 수식 `5` 표시가 **1회 더 많다**. 실제 위치는 "explicit completion stage 5 cannot be an independent first branch"에서 단계 번호를 수식으로 둘러쓴 차이다. 한국어판도 같은 단계를 글로 서술한다.
- 나머지 절에서는 해당 정규화 방식의 인라인 수식 **다중집합이 일치**한다. 다른 절에서 인라인 배열이 재배열된 곳은 있으므로 **222개 개별 위치 순서의 완전한 1:1 대응**이라 부르지는 않는다.
- 현지화된 수식 내부 `\\text{...}`의 문장 뜻과 본문 모든 자연어 전칭·타입 전제의 완전 동치 검증은 이 계산으로 해결되지 않는다.

**판정:** 발견한 두 추가/누락 인라인 수식 표기는 편집적 차이로 설명 가능하며, 이번 검사에서 서로 배타적인 등식·불일치 공리는 발견하지 못했다. 이것은 번역 전체 무오류 인증이 아니다.

## 4. A / B1 / B2의 조건부 수학적 선택지 (결정·흡수·폐기 없음)

| 대안 | 원시자료·정확 보존 | 단계 비교와 엄격 동형 | 추가로 정의해야 할 사항 |
|---|---|---|---|
| A | 활성 인덱스의 정확한 제한 가족, C1이 전부 보존 | 현행 active strict와 `I4` 일치 | 가족의 정확 인덱스; raw 잉여가 필요하면 모형 외부의 별도 보존 구조 |
| B1 | 적법 raw 자료를 모형에 보존, `Comp_raw`에서 전체 raw 유지 | strict/`I_k`는 `N(P)` 활성 코어만 비교, raw 전체 동일성과 구별 | raw 타입·인덱스, N, 기술자 이원화, 원시자료 보존 규칙 |
| B2 | 적법 raw 자료를 모형에 보존, `Comp_raw` 유지 | raw 좌표까지 `I_k^{raw}` 비교, 별도의 강화 `≅_{raw}` 필요 | B1의 모든 raw 규약에 더해 전체 사상·매장·동형·최초분기 정리 보완 |

세 대안은 동일한 목적함수로 점수화하지 않는다. **'추가 편집이 적다'는 A의 장점**은 사실상 정보보존을 원하는 다른 목표에서 B의 가치를 부정하지 않는다. B1과 B2 역시 같은 `strict` 정의의 두 이름이 아니라 **비교할 동일성 층위 자체가 다른 별도 해석**이다. 지금은 선택하지 않는다.
