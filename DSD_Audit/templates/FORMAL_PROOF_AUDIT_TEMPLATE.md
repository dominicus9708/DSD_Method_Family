Require exact citations into frozen source. If the paper states a proof but its adequacy has not yet been reviewed, mark NOT_REVIEWED; do not automatically fill PROVED. When counterexample search returns none in a finite bound, keep arbitrary models OPEN. If theorem statement changes during repair, start a new source lock and link the old verdict; never overwrite a historical verdict.
