## 2. Standard structures to keep separate

### 2.1 Pointwise unitary family

A family

\[
t\mapsto U(t)
\]

is pointwise unitary when

\[
U(t)^\dagger U(t)=I
\]

for every admitted time.

This says nothing by itself about composition across different times.

### 2.2 Two-parameter propagator

A unitary propagator is more naturally written

\[
U(t,s),
\]

with

\[
U(t,t)=I,
\]

\[
U(t,s)^\dagger=U(s,t),
\]

and the cocycle/composition condition

\[
\boxed{
U(t,s)U(s,r)=U(t,r).
}
\]

This permits explicitly time-dependent dynamics.

### 2.3 Time-homogeneous one-parameter group

A one-parameter unitary group has one time-difference parameter and satisfies

\[
U(0)=I,
\]

\[
\boxed{
U(t+s)=U(t)U(s)
}
\]

for all real \(s,t\), together with an appropriate continuity condition.

This is the structure to which Stone's theorem applies.

## 3. Finite-dimensional Hamiltonian generator theorem

Let

\[
U:\mathbb R\to U(d)
\]

be a continuous one-parameter unitary group.

In finite dimension, the standard finite-dimensional form of Stone's theorem gives a unique Hermitian matrix \(H\) such that, with the physical convention including \(\hbar\),

\[
\boxed{
U(t)=e^{-itH/\hbar}.
}
\]

Because every finite-dimensional operator is bounded, the generator has the full Hilbert space as its domain and the map is differentiable.

Therefore

\[
i\hbar\frac{d}{dt}U(t)=HU(t),
\]

and for every state vector

\[
|\psi(t)\rangle=U(t)|\psi(0)\rangle
\]

one obtains

\[
\boxed{
i\hbar\frac{d}{dt}|\psi(t)\rangle
=
H|\psi(t)\rangle.
}
\]

Thus the finite-dimensional implication is

\[
\boxed{
\text{continuous one-parameter unitary group}
\Longrightarrow
\text{time-independent Hermitian generator}.
}
\]

The group condition is substantive.

Continuity plus pointwise unitarity alone is not sufficient.

## 4. Exact counterexample: smooth unitary path without a time-independent generator

Fix a nonzero Hermitian operator \(H_0\) and define

\[
\boxed{
W(t)=e^{-it^2H_0/\hbar}.
}
\]

For every \(t\),

\[
W(t)^\dagger W(t)=I,
\]

and \(W(t)\) is smooth.

However,

\[
W(t+s)
=
e^{-i(t+s)^2H_0/\hbar},
\]

while

\[
W(t)W(s)
=
e^{-i(t^2+s^2)H_0/\hbar}.
\]

Except in trivial cases,

\[
\boxed{
W(t+s)\ne W(t)W(s).
}
\]

Hence

\[
\boxed{
\text{smooth unitary path}
\not\Rightarrow
\text{one-parameter unitary group}.
}
\]

It follows in particular that smooth pointwise unitary reversibility does not imply a time-independent Hamiltonian.

## 5. Refinement: the same counterexample does have a time-dependent Hamiltonian

The previous counterexample must not be overstated.

Differentiate

\[
W(t)=e^{-it^2H_0/\hbar}.
\]

Since the generator at different times is proportional to the same \(H_0\),

\[
i\hbar\,\dot W(t)
=
2tH_0\,W(t).
\]

Therefore the path is generated by

\[
\boxed{
H(t)=2tH_0.
}
\]

This gives the sharper distinction

\[
\boxed{
\text{smooth unitary path}
\not\Rightarrow
\text{time-independent }H,
}
\]

while, in finite dimension, a differentiable unitary path admits an instantaneous Hermitian generator

\[
\boxed{
H(t)=i\hbar\,\dot U(t)U(t)^\dagger.
}
\]

Hermiticity follows by differentiating

\[
U(t)U(t)^\dagger=I.
\]

Thus 005D does not reject Hamiltonian generation for general smooth unitary motion.

It separates **time-dependent** from **time-independent** Hamiltonian structure.

## 6. Continuity alone does not imply an ordinary time-dependent Schrödinger equation

Consider

\[
N(t)=e^{-i|t|H_0/\hbar}.
\]

This family is continuous and unitary for all \(t\), but its one-sided derivatives at \(t=0\) are

\[
\dot N(0^+)
=
-\frac{i}{\hbar}H_0,
\]

\[
\dot N(0^-)
=
+\frac{i}{\hbar}H_0.
\]

For nonzero \(H_0\) they disagree.

Therefore

\[
\boxed{
\text{continuous unitary path}
\not\Rightarrow
\text{differentiable unitary path}.
}
\]

A general continuous time-indexed unitary family therefore does not automatically possess an ordinary pointwise Hamiltonian \(H(t)\) at every time.

This does not conflict with Stone's theorem because \(N(t)\) is not a one-parameter group.

## 7. Two-parameter propagator and time-dependent Hamiltonian

Suppose a differentiable unitary propagator satisfies

\[
U(t,s)U(s,r)=U(t,r).
\]

Define

\[
\boxed{
H(t)
=
i\hbar\,\partial_tU(t,s)\,U(s,t).
}
\]

Using the cocycle law, the right-hand side is independent of the chosen reference time \(s\) whenever the required differentiability holds.

Unitarity implies that \(H(t)\) is Hermitian.

The propagator then satisfies

\[
\boxed{
i\hbar\,\partial_tU(t,s)
=
H(t)U(t,s).
}
\]

For a general time-dependent Hamiltonian,

\[
[H(t_1),H(t_2)]
\]

need not vanish.

The propagator is then represented by the standard time-ordered exponential

\[
U(t,s)
=
\mathcal T
\exp\left[
-\frac{i}{\hbar}
\int_s^t H(\tau)\,d\tau
\right],
\]

under the usual existence/regularity assumptions.

Thus

\[
\boxed{
\text{unitary propagator}
\not\Rightarrow
e^{-i(t-s)H/\hbar}
\text{ for one fixed }H.
}
\]

If time homogeneity is additionally imposed,

\[
U(t,s)=V(t-s),
\]

then the propagator composition law gives

\[
V(t+s)=V(t)V(s),
\]

and Stone's theorem becomes applicable to \(V\).

## 8. Infinite-dimensional boundary: Stone's theorem and domains

For a general Hilbert space, the correct standard theorem is:

> Every strongly continuous one-parameter unitary group \(U(t)\) has a unique self-adjoint generator \(H\) such that
>
> \[
> U(t)=e^{-itH/\hbar}.
> \]

The generator may be unbounded.

Therefore the Schrödinger differential equation is not automatically an equation on every vector in the Hilbert space.

For

\[
\psi\in D(H),
\]

one has

\[
i\hbar\frac{d}{dt}U(t)\psi
=
HU(t)\psi.
\]

Vectors outside \(D(H)\) still have a strongly continuous unitary orbit, but the strong derivative need not exist.

Consequently the implication must be recorded as

\[
\boxed{
\text{strongly continuous unitary group}
\Rightarrow
\text{self-adjoint generator},
}
\]

but

\[
\boxed{
\text{Schrödinger differential equation for a vector}
}
\]

requires the appropriate generator-domain condition.

In finite dimension this domain issue disappears.

Standard references include Stone's theorem on strongly continuous one-parameter unitary groups and standard quantum-mechanics treatments of time-dependent propagators; MIT OpenCourseWare's *Quantum Physics II* notes give the time-ordered form for general noncommuting \(H(t)\).

## 9. Channel-level phase / energy-zero boundary

QM Core 005C is formulated primarily at the density-operator channel level:

\[
\Phi_t(\rho)=U(t)\rho U(t)^\dagger.
\]

The unitary representative is not unique.

For any real phase \(\theta(t)\),

\[
U(t)
\mapsto
e^{-i\theta(t)}U(t)
\]

produces the same channel.

For a time-independent generator this includes

\[
H\mapsto H+cI,
\]

because

\[
e^{-it(H+cI)/\hbar}
=
e^{-ict/\hbar}e^{-itH/\hbar},
\]

and the global phase cancels in conjugation.

Therefore

\[
\boxed{
\operatorname{Ad}_{e^{-itH/\hbar}}
=
\operatorname{Ad}_{e^{-it(H+cI)/\hbar}}.
}
\]

At channel level the infinitesimal Hamiltonian action is

\[
\mathcal L_H(\rho)
=
-\frac{i}{\hbar}[H,\rho],
\]

and

\[
\mathcal L_{H+cI}
=
\mathcal L_H.
\]

Hence a density-channel reconstruction determines the Hamiltonian only up to the standard additive scalar freedom unless an additional phase/energy-zero convention is supplied.

This is not a DSD defect.

It is a standard information-loss/gauge fact of the density-operator representation.
