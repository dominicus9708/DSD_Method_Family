## 1. Research question

The selected external reconstruction comparator uses the Subspace Axiom in the following form: for a capacity-`N` system and a complete measurement `E_1,...,E_N`, the zero-probability face for an excluded outcome must be equivalent to the capacity-`N-1` system. The equivalence is linear at state-space level and includes the reversible transformations induced on the retained face.

The current DSD quantum specialization already had a weaker `RRDE-QM` idea tied to a declared maximal measurement and its excluded outcomes. QM Core 004E therefore introduced

```text
ULRRDE-QM
Universal Linear Recursive Restriction Equivalence
```

as an exact theorem-interface lock.

This audit asks:

1. Does one designated recursive measurement imply the same recursion for every complete measurement?
2. Does connected pure-state transitivity `CRG-QM` make all complete measurements equivalent?
3. Does an equivalence that intertwines selected retained dynamics automatically identify the full face-preserving reversible group?
4. Can the universal condition be decomposed into smaller assumptions plus a theorem?

The answer is:

```text
one designated recursive measurement -> universal recursion             NO
connected pure-state transitivity -> complete-measurement transitivity   NO
selected retained dynamics -> full stabilizer-group equivalence          NO
reference full-face recursion + complete-measurement transitivity        YES
```

Thus the old monolithic `ULRRDE-QM` entry is too coarse.

## 2. Source lock — DSD

The Formation Axiom System distinguishes restriction, embedding, submodel, and strict base-fixed formation isomorphism. Strict formation equivalence requires the full preservation/reflection data of Definition 6.10.

Therefore:

\[
\boxed{

\not\Rightarrow
\text{strict formation equivalence to a lower system type}.
}
\]

### 2.2 Property submodels are not automatically lower physical systems

The Property Axiom System similarly distinguishes forward maps, embeddings, inclusion submodels, strict core property isomorphism, and representation-inclusive strict equivalence. A retained property domain is not automatically identified with another system type.

### 2.3 Dynamics lineage does not supply reversible-group equivalence

Structural Reorganization Dynamics supplies component-resolved trajectories and lineage when formation-level identity changes. It does not require every reversible symmetry of a retained face to be generated by, or conjugate to, a lower-system reversible group.

Hence the exact external Subspace equivalence is additional physical specialization structure, not a generic consequence of DSD restriction syntax.

## 5. Capacity is exactly two

Any affine effect on `D^2 x D^2` can be written

\[
e(x,y)=\alpha+a\cdot x+b\cdot y.
\]

Its extrema are

\[
\alpha\pm(\|a\|+\|b\|).
\]

If an effect in a perfect distinguishing measurement takes value `1` on one pure state and `0` on two others, it attains its global maximum and minimum. Hence every factor with nonzero coefficient is fixed to the maximizing direction on the distinguished state and to the opposite minimizing direction on all other states.

Suppose three states were jointly perfectly distinguishable. For each of the three outcome effects select one factor, `X` or `Y`, on which that effect has nonzero coefficient. By pigeonhole, two effects select the same factor.

If effects `i` and `j` both select `X`, then perfect distinguishability requires

\[
x_j=x_k=-x_i,
\qquad
x_i=x_k=-x_j,
\]

which is impossible. The same argument holds for `Y`.

Therefore no three states are jointly perfectly distinguishable:

\[
\operatorname{Cap}(K)\le2.
\]

A binary distinguishing measurement exists, so

\[
\boxed{\operatorname{Cap}(K)=2}.
\]

The companion Python script exhausts the two-factor support choices used by this proof and verifies the explicit binary witnesses.

## 6. One complete measurement passes the recursive face test

Define

\[
e_D(x,y)
=
\frac12+rac14(x_1+y_1).
\]

Because `x_1,y_1 in [-1,1]`, this is a valid effect, and

\[
\{e_D,1-e_D\}
\]

is a complete binary measurement.

Its zero face is

\[
F_D
=
\{(x,y):e_D(x,y)=0\}.
\]

The equation `e_D=0` gives

\[
x_1+y_1=-2.
\]

Since neither coordinate is below `-1`, necessarily

\[
x_1=y_1=-1.
\]

Disk membership then forces

\[
x=(-1,0),
\qquad
y=(-1,0).
\]

Therefore

\[
\boxed{F_D\text{ is a singleton}.}
\]

A capacity-one state space is a singleton in the comparator framework, so this designated measurement passes the `Q_2 -> Q_1` state-face recursion.

Its face-preserving reversible action is also trivial, matching the capacity-one reversible dynamics.

Thus one reference recursive measurement can pass exactly.

## 7. Another complete measurement fails the same recursion

Define

\[
e_X(x,y)=\frac{1+x_1}{2}.
\]

Again

\[
\{e_X,1-e_X\}
\]

is a complete binary measurement.

Its zero face is

\[
F_X
=
\{(x,y):x=(-1,0),\ y\in D^2\}.
\]

Hence

\[
F_X\cong D^2,
\]

not a singleton.

Indeed the retained states

\[
((-1,0),(1,0)),
\qquad
((-1,0),(-1,0))
\]

are perfectly distinguished by

\[
e_Y(x,y)=\frac{1+y_1}{2}.
\]

Therefore

\[
\operatorname{Cap}(F_X)\ge2,
\]

so `F_X` cannot be equivalent to the capacity-one system.

Thus:

\[
\boxed{
\text{one complete measurement passes recursion}
\not\Rightarrow
\text{all complete measurements pass recursion}.
}
\]

This is a concrete convex operational countermodel, not only a logical truth-table witness.

## 8. CRG-QM does not supply complete-measurement transitivity

The same model also shows that connected pure-state transitivity is weaker than transitivity on complete distinguishing frames.

Consider two complete binary frames.

### Frame A

\[
((1,0),(1,0)),
\quad
((-1,0),(1,0)).
\]

The factorwise pair invariants are

\[
(x_1\cdot x_2,\ y_1\cdot y_2)=(-1,+1).
\]

### Frame D

\[
((1,0),(1,0)),
\quad
((-1,0),(-1,0)).
\]

The invariants are

\[
(-1,-1).
\]

Every element of `SO(2) x SO(2)` preserves the two factorwise inner products separately. Hence the two complete frames lie in different reversible-group orbits.

Therefore:

\[
\boxed{
\text{connected reversible group + pure-state transitivity}
\not\Rightarrow
\text{complete-measurement/frame transitivity}.
}
\]

This closes a possible shortcut from `CRG-QM` to universal recursive restriction.

## 9. Selected retained dynamics are weaker than full face dynamics

The exact comparator equivalence uses the reversible transformations of the retained lower-capacity system, not merely one selected subgroup that happens to intertwine with a chosen DSD dynamics.

Abstract control:

```text
lower-system reversible group        SO(2)
selected retained face dynamics      SO(2)
full face-preserving group           O(2)
```

The selected subgroup can match the lower system, while the full group cannot be conjugate to it: `SO(2)` is abelian, whereas `O(2)` contains reflections that do not commute with generic rotations.

Hence:

\[
\boxed{
\text{selected-dynamics intertwining}
\not\Rightarrow
\text{full face-stabilizer conjugacy}.
}
\]

The old `RRDE-QM` wording must therefore be sharpened before it can instantiate the exact external Subspace equivalence.

## 10. Decomposition theorem for the universal condition

The universal quantifier itself need not remain a primitive monolithic lock.

Define two exact interfaces.

### 10.1 LFRR-QM — Linear Full Reference Recursion

Choose one reference complete measurement

\[
M_N^0=\{e_1^0,\ldots,e_N^0\}.
\]

For every outcome `i`, let

\[
F_i^0
=
\{\omega\in\Omega_N:e_i^0(\omega)=0\}.
\]

Require an invertible linear equivalence

\[
L_i^0:\operatorname{span}(F_i^0)
\longrightarrow V_{N-1}
\]

mapping normalized states onto `Omega_(N-1)` and conjugating the full induced face-preserving reversible transformation group to `G_(N-1)`.

### 10.2 CMT-QM — Complete-Measurement Transitivity

For every complete measurement

\[
M=\{e_1,\ldots,e_N\}
\]

require a reversible transformation `T in G_N` and a permutation `pi` such that

\[
e_i
=
e_{\pi(i)}^0\circ T^{-1}.
\]

Then

\[
F_i=T(F_{\pi(i)}^0).
\]

### 10.3 Transfer theorem

If `LFRR-QM` and `CMT-QM` hold, define

\[
L_i
=
L_{\pi(i)}^0\circ T^{-1}.
\]

Then `L_i` is an invertible linear equivalence from the arbitrary zero face `F_i` to the lower-capacity state space.

Moreover stabilizers transform by conjugation:

\[
G_{F_i}
=
T G_{F_{\pi(i)}^0} T^{-1}.
\]

Therefore the reference full-face dynamical equivalence transfers to every complete measurement.

Hence:

\[
\boxed{
\text{LFRR-QM}
+
\text{CMT-QM}
\Longrightarrow
\text{ULRRDE-QM}.
}
\]

This is a conditional mathematical transfer theorem.
