## Main result
The expanded standard-theory audit supports six distinct questions that should remain separate in DSD analysis:

1. IDENTIFIABILITY — does a readout distinguish the admitted states?
2. DISTINGUISHABILITY MONOTONICITY — how does a supplied process change a quantitative state distinction?
3. COMPLETABILITY — can the observed record be represented inside a restricted model class?
4. RECOVERABILITY/SUFFICIENCY — can a supplied recovery map restore the relevant complete state family?
5. ACCESSIBILITY/CAUSALITY — which local algebra, support, observer trajectory, or protocol can access the distinction?
6. REPRESENTATION EQUIVALENCE — is a coordinate/frame/modular description change invertible on the admitted class?

These are not interchangeable.
