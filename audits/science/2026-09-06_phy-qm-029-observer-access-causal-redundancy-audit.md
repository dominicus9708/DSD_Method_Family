## Part A — Physical redundancy versus observer-access capacity
Normalize the sufficient-fragment threshold to 1 and use six environment units with

\[
w_i=0.6.
\]

The physical environment can be partitioned into three disjoint sufficient pairs, so

\[
R_{phys}=3.
\]

Now add an explicit observer-access relation.

### Distributed access

```text
O1 -> {0,1}
O2 -> {2,3}
O3 -> {4,5}
```

Each observer can be assigned a distinct sufficient pair, hence

\[
R_{obs}^{disj}=3.
\]

### Shared bottleneck

```text
O1 -> {0,1}
O2 -> {0,1}
O3 -> {0,1}
```

The same physical environment still has R_phys=3, but at most one observer can receive a pairwise-disjoint sufficient fragment under the declared access relation:

\[
R_{obs}^{disj}=1.
\]

Therefore

\[
\boxed{
\text{physical redundancy}
\neq
\text{multi-observer operational accessibility}.
}
\]

The disjoint-observer capacity used here is an explicit DSD audit diagnostic; it is not asserted to be the unique notion of observer independence in Quantum Darwinism.

## Part B — Conditional causal availability
To connect the quantum-record problem to the DSD dynamics interface, add a localization carrier, distances d_i from the record-generating region, and a finite structural information-propagation bound c_info. This is a conditional DSD specialization, not a consequence of static Quantum Darwinism alone.

If a record is generated by a local disturbance after t=0, then before time t only components satisfying

\[
d_i\le c_{info}t
\]

can be included in the causally reachable record support, under the declared support-faithful propagation model.

Define

\[
E_t:=\{i:d_i\le c_{info}t\},
\]

and the reachable redundancy diagnostic

\[
R_\delta^{reach}(t)
:=R_\delta^{disj,opt}(E_t).
\]

For the control

```text
weights   = [0.6,0.6,0.6,0.6,0.6,0.6]
distances = [1.0,1.2,2.1,2.3,3.1,3.2]
c_info    = 1
```

the exact solver gives

```text
t=1.0 -> reachable [0]           -> R_reach=0
t=1.2 -> reachable [0,1]         -> R_reach=1
t=2.3 -> reachable [0,1,2,3]     -> R_reach=2
t=3.2 -> reachable [0,1,2,3,4,5] -> R_reach=3
```

Thus a static environment may have high eventual redundancy while the redundancy operationally available from a local generation event is time-indexed.

## DSD interpretation
This produces a clean separation:

```text
record existence
physical support distribution
observer access relation
causal reachability
threshold sufficiency
multi-observer assignment
```

None should be silently replaced by another.

The current DSD dynamics already defines descriptive accessibility by an explicit projection and finite information propagation at the component-support level; this audit supplies a quantum-record specialization of those interfaces rather than a new foundational axiom.

## Caution
No claim is made that standard quantum entanglement or Quantum Darwinism by itself has a signal speed c_info. The causal restriction applies only after a localization carrier, local record-generation mechanism, metric time, discrepancy convention, and finite-propagation law have been supplied.
