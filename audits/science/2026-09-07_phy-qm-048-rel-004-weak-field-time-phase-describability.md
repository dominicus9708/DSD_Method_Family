## 1. Relativistic weak-field control

For a static weak gravitational potential \(\Phi\) with

\[
|\Phi|/c^2\ll1,
\]

use the standard first-order weak-field metric convention

\[
ds^2
\approx
-\left(1+\frac{2\Phi}{c^2}\right)c^2dt^2
+\left(1-\frac{2\Phi}{c^2}\right)d\mathbf x^2.
\]

For a stationary clock, \(d\mathbf x=0\), so

\[
d\tau
=\sqrt{1+\frac{2\Phi}{c^2}}\,dt
\approx
\left(1+\frac{\Phi}{c^2}\right)dt.
\]

For two stationary branches held for the same coordinate interval \(T\),

\[
\boxed{
\Delta\tau
\approx
\frac{\Delta\Phi}{c^2}T
}
\]

to first order.

This already separates

```text
coordinate holding time T
!= proper-time difference Delta tau.
```

## 2. Standard quantum control on the supplied classical potential

Use the nonrelativistic Schrödinger equation

\[
i\hbar\partial_t\psi
=
\left[
-\frac{\hbar^2}{2m}\nabla^2
+m\Phi
\right]\psi.
\]

For a branch held at a fixed potential \(\Phi\), the potential term contributes phase

\[
\varphi_\Phi
=-\frac{m\Phi T}{\hbar}.
\]

Hence two stationary branches acquire relative phase

\[
\boxed{
\Delta\varphi
=-\frac{m\Delta\Phi T}{\hbar}
}
\]

under this supplied classical-background specialization.

Combining only the two standard first-order relations above gives

\[
\boxed{
\Delta\varphi
\approx
-\frac{mc^2}{\hbar}\Delta\tau
}
\]

for the controlled setup.

### Boundary

This equality is not a universal quantum-gravity law. It is a correspondence between:

```text
1. the weak-field proper-time difference of the supplied classical background,
2. the ordinary Schrödinger phase generated by V=m Phi,
```

under the stated stationary, weak-field, nonrelativistic assumptions.

## 4. PHY-QM-048 — phase-to-readout non-injectivity

For an equal-amplitude two-path recombination control, take

\[
P_+(\Delta\varphi)
=
\frac{1+\cos\Delta\varphi}{2}.
\]

Then

\[
P_+(\theta)
=
P_+(\theta+2\pi k)
=
P_+(-\theta+2\pi k)
\]

for integer \(k\).

Therefore the probability readout fiber contains multiple phases:

\[
\boxed{
P_+(\Delta\varphi)
\text{ does not uniquely reconstruct }
\Delta\varphi
}
\]

without additional measurements or a restricted phase domain.

Even a phase known only modulo \(2\pi\) does not retain the unwrapped winding count of the accumulated action.

### DSD consequence

There are at least three distinct records:

```text

phase modulo 2pi,
selected interference probability.
```

Equality at the last level does not establish equality at the first two.

## 5. Parameter-identifiability obstruction

Both the first-order proper-time difference and the potential-induced phase depend on the product

\[
\Delta\Phi\,T.
\]

Thus two distinct parameter pairs can satisfy

\[
\Delta\Phi_1T_1
=
\Delta\Phi_2T_2
\]

while

\[
(\Delta\Phi_1,T_1)
e(\Delta\Phi_2,T_2).
\]

They then produce the same first-order \(\Delta\tau\) and the same \(\Delta\varphi\) for fixed \(m\).

Therefore

\[
\boxed{
\Delta\tau\text{ or }\Delta\varphi
\not\Rightarrow
\text{unique reconstruction of }(\Delta\Phi,T)
}
\]

without an independent measurement of one of the factors.

This is a direct DSD reconstruction/identifiability witness using only standard theory.
